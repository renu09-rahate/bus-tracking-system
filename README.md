# FitSoul App

## About
FitSoul App is a Java-based BMI Calculator that helps users calculate their Body Mass Index (BMI), check their health status, and receive basic diet suggestions.

## Features
- Calculate BMI
- Shows health status (Underweight, Normal, Overweight)
- Provides diet suggestions
- Simple Java GUI

## Technologies Used
- Java
- Swing (GUI)
